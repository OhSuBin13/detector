기준일 2026-10-06 · 조사만 했고 코드는 바꾸지 않았다 · 관련 문서 `STATUS_AND_PLAN.md`, `../DESIGN.md` 10.5

## 1. 요약

- **지금 의미 게이트(`AdSignals.adLike`)는 놓침과 오탐이 둘 다 있다.**
  - 놓침: 직접 만든 광고 문구 20개 중 8개만 잡는다. "먹튀 피해 예방 안전놀이터"처럼 광고가 스스로 쓰는 피해·예방·불법·단속 같은 말에 막히고, "바카라 필승법 공개"처럼 주제어 하나뿐인 문구는 보조어 점수가 모자라 빠진다.
  - 오탐: 사행산업통합감독위원회(ngcc.go.kr) 6쪽 점검에서 **오탐 3건**이 실제로 나왔다(FAQ 답변 2, 전자책 페이지 1). 긴 정상 글에 서로 다른 주제어가 모이면(카지노 2 + 경마 1) 점수 3을 넘기 때문이다.
- **구조 신호만으로 "숨김 의도"를 판정할 수는 없다.** 공식 예시와 모의 사이트 정답이 `visually-hidden`·`sr-only`·footer·형제 목록처럼 정상 숨김과 같은 구조를 쓴다. 접근성 숨김, 토글, footer, 형제 신호는 정답을 5~33건씩 잃는다.
- **가장 강한 판별 신호는 숨긴 요소의 "글 길이와 키워드 밀도"다.**
  - 실사이트 숨김 요소 2,042개 중 가중치 2 이상 키워드가 든 정상 숨김은 10개뿐이고 모두 213자 이상, 밀도 0.02 이하였다.
  - 모의 사이트 숨긴 광고는 모두 29자 이하, 밀도 0.13 이상이다.
- 구조 신호 중 쓸 만한 것은 **메뉴 억제**(nav, GNB 하위 메뉴, FAQ처럼 보이는 링크가 있는 `li` 안의 숨김) 하나다. 잃는 정답이 0이고 모의 대조군 키워드 오탐의 82%를 걸러 낸다.

## 2. 조사 방법과 표본

### 2.1 도구
프로젝트 코드는 그대로 두고 빌드된 배포본(`build/dist/ad-detector`)을 클래스패스로 쓰는 임시 도구로 측정했다. 도구는 세션 임시 폴더에 있다(9장).

1. `FrameSnapshot.collect`로 숨김 후보를 모두 모은다. 의미 게이트를 거치기 전 상태다.
2. `TransparentAnalyzer`, `OffscreenAnalyzer`, visibility, clip 신호로 `HiddenDetector`와 똑같이 root(숨김이 걸린 요소)별로 묶는다.
3. root마다 구조 특징을 브라우저에서 뽑는다: 태그·class·role·aria, 조상 태그와 위젯·메뉴 클래스, 토글 연결, 인라인 style, 접근성 숨김 CSS 지문, 링크와 외부 호스트, 사용자 작성 영역, 위치, 정답 라벨.
4. root의 글들(holder 글, 합친 글, 300자 이하 root 글)에 `AdSignals.assess`를 돌려 지금 게이트 결과와 키워드를 기록한다.

## 6. 추천안: G6

### 6.1 규칙
숨김 기법(TRANSPARENT, OFFSCREEN, ETC의 visibility·clip)에만 적용한다. JAMO·HOMOGLYPH는 위장 자체가 근거이므로 지금 규칙을 그대로 둔다.

1. **숨긴 요소 단위 조건 (구조)**
   - root 전체 글이 200자 이하이거나 키워드 글자 비율이 기준 이상이어야 한다.
   - 비율은 키워드 **출현 횟수** 기준으로 센다. 링크 수십 개짜리 주입 스팸 목록이 길어도 통과하게 하기 위해서다.
   - 구현에서는 "키워드 출현 글자 / 공백 뺀 글자"로 세므로 조사 때의 계산(중복 없는 키워드 글자 / 공백 포함 길이)보다 값이 두 배쯤 크다. 같은 표본을 이 방식으로 다시 재면 정상 긴 글은 최대 0.053, 숨긴 광고는 최소 0.158이라 기준을 **0.1**로 정했다(10장).
2. **메뉴 억제 (구조)**: root나 그 조상이 nav이거나, GNB 하위 메뉴(같은 `li`에 보이는 링크·버튼)이거나, 메뉴 클래스(gnb, lnb, snb, allmenu, sitemap, depth2, submenu 등)면 보고하지 않는다.
3. **키워드 규칙 (단순화)**
   - 가중치 2 이상 키워드가 있어야 한다.
   - 연락처(메신저, 전화, 외부 도메인, 단축 URL·t.me)가 있으면 통과한다.
   - 전용어(가중치 3)는 강한 보도 문맥어가 2개 이상일 때만 막는다.
   - 주제어(가중치 2)만 있으면 보도·예방 문맥어가 하나라도 있을 때 막는다.
   - 보조어 점수(`score() >= 3`)와 `bare()` 규칙은 숨김 기법에서는 쓰지 않는다.

### 6.3 정해야 할 것
G6는 직접 만든 대조군 2건을 오탐한다. 지금 완료 기준(M2 "대조군 오탐 0")을 지키려면 둘 중 하나를 고른다.

- **(a) 규칙 보완**: "기자", "기사"를 강한 문맥어에 넣어 "관련 기사…"를 막는다. "카지노업 현황"처럼 주제어만 있는 짧은 숨긴 글은 G0의 `bare()`(키워드가 글의 70% 이상)를 주제어 단독일 때만 남긴다. 그러면 "바카라 필승법 공개"류를 다시 놓친다.

**결정 (2026-10-07)**: 부분 보완.
- "기사"를 강한 문맥어에 넣어 "관련 기사…" 대조군을 막는다.

- 지금 `adLike()`는 그대로 두고 6.1의 1·2번(길이·밀도, 메뉴)만 덧붙인다. 6.2의 3번 중 `hiddenAdLike()`를 빼면 된다(약 1일).
- 모의 사이트 44/44에 오탐 0, 실사이트 오탐 0으로 사감위형 오탐은 없어진다.

## 8. 한계와 범위 밖

- **표본이 작다.** 실사이트 4곳 28쪽이고, 키워드 든 정상 숨김은 ngcc 한 곳의 10건뿐이다. 임계값 200자, 0.05는 이 표본에서 정했다. 광고 쪽 최대 29자·0.13과 정상 쪽 최소 213자·0.02 사이의 여유는 크지만, 다른 사행 관련 기관(경륜·경정, 복권, 강원랜드)으로 더 확인하는 것이 좋다.
- **실제 숨긴 광고 표본이 없다.** 정답은 모의 사이트와 직접 만든 문구뿐이라 실제 재현율은 모른다. 관련 연구의 실제 주입 사례는 대부분 인라인 `display:none`이나 화면 밖 위치였고, 외부 링크 여러 개를 담은 목록이었다. 그래서 밀도를 출현 횟수로 세는 것이 중요하다.
- 덤프는 root 단위로 계산했고, 안쪽이 보고되면 조상을 빼는 처리는 간이로 했다.
- **범위 밖이지만 중요한 것**
  - 2025년 공공기관 61곳·1,169건 사례의 다수는 CSS 숨김이 아니라 **검색창 반사**다. 검색어가 결과 페이지에 보이는 글로 찍히고 텔레그램 아이디가 함께 나온다. 4기법 정의 밖이라 ETC 후보다.
  - 클로킹(봇에게만 다른 내용)은 같은 주소를 다른 User-Agent로 한 번 더 받아 외부 링크·키워드만 비교하면 싸게 확인할 수 있다. 이것도 ETC 후보다.
