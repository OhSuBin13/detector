# ad-detector 사용설명서

## 1. 한눈에 보기 (첫 장)

| 항목 | 내용 |
|---|---|
| 하는 일 | 웹사이트 주소(URL) 하나를 넣으면 그 사이트의 페이지·게시글·댓글·iframe 안에 게시·은닉된 불법광고를 찾아 유형과 위치를 알려 줍니다. |
| 실행 환경 | Windows 11 (GPU 불필요, 인터넷 연결 불필요 — 점검 대상 사이트에만 접속) |
| 실행 파일 | `ad-detector-ui.bat` (결과 화면), `ad-detector.bat` (명령줄) |
| 설치 | 없음. 배포 폴더를 그대로 복사해 씁니다. Java·브라우저가 폴더 안에 들어 있습니다. |
| 상용 AI API | **사용하지 않습니다.** API KEY, `.env` 파일, 외부 서버가 필요 없습니다. |

### 결과 파일 생성 경로

| 파일 | 생성 경로 | 내용 |
|---|---|---|
| **`result.json`** | **실행 파일(`ad-detector.bat`, `ad-detector-ui.bat`)이 있는 폴더** | 적격평가용 결과(주요 탐지 유형 4종) |
| **`result_extra.json`** | 같은 폴더 | 추가 탐지 유형(ETC) 결과 |
| `report.html` | 같은 폴더 | 더블클릭으로 여는 결과 화면 |
| `report.json`, `review.json` | 같은 폴더 | 탐지 근거·통계, 처리 상태·메모 |

- 명령줄에서 `--out 폴더`를 주면 그 폴더에 생성합니다.
- 실행 파일이 있는 폴더에 쓸 수 없으면(읽기 전용 등) 현재 폴더, 그다음 `%USERPROFILE%\ad-detector` 순으로 쓰고,
  실제로 쓴 경로를 화면에 표시합니다.

### 가장 빠른 사용 순서

1. `ad-detector-ui.bat`을 더블클릭합니다. 브라우저에 결과 화면이 열립니다.
2. 점검할 웹사이트 주소를 넣고 **탐지 시작**을 누릅니다.
3. **탐지 완료** 알림이 뜨면 화면에서 결과를 확인합니다. `result.json`은 실행 파일이 있는 폴더에 생겨 있습니다.

명령줄로는 `ad-detector.bat https://www.example.go.kr` 한 줄입니다.

## 2. 결과 화면으로 점검하기

`ad-detector-ui.bat`을 실행하면 검은 창(서버)이 뜨고 기본 브라우저에 화면이 열립니다.
화면은 이 PC에서만 접속됩니다(`http://127.0.0.1:8787`). 끝내려면 검은 창을 닫습니다.

### 점검 시작

| 입력 | 뜻 | 기본값 |
|---|---|---|
| 점검할 웹사이트 주소 | 진입 URL. 이 주소의 호스트 안에서만 돌아다닙니다. | — |
| 시간 예산(분) | 이 시간 안에 결과를 기록하고 끝냅니다. 대기열이 비면 더 일찍 끝납니다. | 25 |
| 동시 브라우저 | 동시에 여는 브라우저 수. 운영 중인 사이트는 1~2를 권장합니다. | PC 사양에 따라 1~3 |

진행 중에는 방문한 페이지 수, 남은 대기 수, 탐지 건수, 경과 시간이 표시되고 탐지되는 대로 목록에 나타납니다.
**중지**를 누르면 그때까지 찾은 결과를 기록하고 끝냅니다.

### 화면 구성

| 영역 | 하는 일 |
|---|---|
| ① 요약 | 전체·기법별 건수, 점검한 페이지 수, 처리 현황(미확인 / 확인 / 조치 / 오탐) |
| ② 거르기 | 기법 버튼, 처리 상태, 검색어(문구·주소·위치)로 거르고, 페이지별로 묶어 봅니다. |
| ③ 근거 | 건을 누르면 펼쳐집니다. 숨겨진 원문, 위장을 풀어 읽은 문구(키워드 강조), 숨긴 방법, 광고로 판단한 키워드 |
| ④ 위치 확인 | CSS 선택자와 페이지 링크. **강조 코드 복사**를 누른 뒤 해당 페이지에서 `F12` → Console에 붙여 넣으면 숨겨진 요소가 노란 바탕·빨간 테두리로 드러납니다. |
| ⑤ 관리 | 건마다 처리 상태(미확인 / 불법광고 확인 / 조치 완료 / 오탐)와 메모를 남깁니다. `review.json`에 저장됩니다. |
| ⑥ 내보내기 | **CSV 내보내기**(Excel에서 바로 열림), **인쇄**(모든 건을 펼쳐 인쇄) |

표시의 뜻:

- **공통 영역 변조 의심 · N쪽**: 같은 문구가 여러 페이지의 같은 위치에 있습니다. 게시글이 아니라 머리글·바닥글 같은 공통 영역(템플릿)이
  변조되었을 가능성이 높습니다. 웹셸·관리자 계정 탈취 여부를 점검하세요.
- **조치 후 재발견**: "조치 완료"로 표시한 건이 다음 점검에서 또 탐지되었습니다.

같은 폴더에서 다시 점검하면 같은 건(같은 페이지·위치·기법)의 처리 상태와 메모가 이어집니다.

### 서버 없이 결과 보기

점검이 끝나면 생기는 `report.html`을 더블클릭하면 같은 화면이 열립니다(검은 창 없이).
이 화면에서 바꾼 처리 상태·메모는 그 PC의 그 브라우저에만 저장되므로, 계속 관리하려면 `ad-detector-ui.bat` 화면을 쓰세요.

## 3. 명령줄로 점검하기

```bat
ad-detector.bat URL [옵션]
```

| 옵션 | 뜻 | 기본값 |
|---|---|---|
| `--out DIR` | 결과 파일을 쓸 폴더 | 실행 파일이 있는 폴더 |
| `--budget-min 분` | 시간 예산 | 25 |
| `--workers N` | 동시 브라우저 수 | PC 사양에 따라 1~3 |
| `--max-pages N` | 방문할 최대 페이지 수 | 제한 없음 |
| `--settle-ms ms` | 로드 뒤 늦게 붙는 내용(댓글 등)을 기다리는 최대 시간 | 1500 |
| `--no-extra` | 추가 유형(ETC) 탐지와 `result_extra.json`을 끔 | 켜짐 |
| `--topic 글` | `result.json`의 `meta.topic` 값 | `TOPIC` |
| `--headed` | 브라우저 창을 띄워서 점검(확인용) | 끔 |
| `--quiet` | 진행 상황을 출력하지 않음 | 끔 |
| `--ui`, `--port N`, `--no-open` | 결과 화면 서버 실행, 포트, 브라우저 자동 열기 끄기 | 8787 |

URL 없이 실행(더블클릭)하면 주소를 물어봅니다.

예:

```bat
ad-detector.bat https://www.example.go.kr
ad-detector.bat https://www.example.go.kr --out D:\점검\10월 --workers 2
```

끝나면 요약과 파일 경로가 출력됩니다.

```
탐지 완료: 정상 완료
  23개 페이지, 7.3초, 탐지 74건 {HOMOGLYPH=15, JAMO=18, TRANSPARENT=16, OFFSCREEN=25}
  채점용 결과: C:\ad-detector\result.json
  결과 화면(더블클릭): C:\ad-detector\report.html
```

종료 코드: `0` 정상(시간 예산 도달·중단 포함), `1` 오류(브라우저 실행 실패, 진입 주소 접속 실패, 결과 파일 쓰기 실패), `2` 잘못된 주소.
어느 경우든 `result.json`은 기록합니다(검출이 없으면 `findings`는 빈 배열).

## 4. 무엇을 탐지하나

### 주요 탐지 유형 4종 (`result.json`)

| 기법 | 탐지하는 것 |
|---|---|
| `HOMOGLYPH` 닮은꼴 글자 위장 | 전각·수학용·원문자 영문(`ｃａｓｉｎｏ`, `ⓒⓐⓢⓘⓝⓞ`), 키릴·그리스 닮은꼴이 섞인 영문, 숫자로 바꿔 쓴 영문(`c4s1no`), 한글 자리에 닮은 글자를 넣은 것(`7r지노`) |
| `JAMO` 자모 분해 | 풀어 쓴 자모(`ㅋㅏㅈㅣㄴㅗ`), 글자마다 구분자를 끼운 것(`ㅂ.ㅏ.ㅋ.ㅏ`), 일부만 푼 것(`카ㅈㅣ노`), 글 사이에 흩어 놓은 자모, 반각 자모, 자모에 닮은꼴을 섞은 것(`ㅋr지노`) |
| `TRANSPARENT` 투명 텍스트 | `opacity` 0~0.1(조상 누적), `color:transparent`·알파 0, `-webkit-text-fill-color:transparent`, 배경색과 같은 글자색(대비 1.1 이하), `filter:opacity(0)` |
| `OFFSCREEN` 화면 밖 은닉 | `display:none`·`hidden`, `font-size` 0~1px, 화면 밖 위치(`left/top:-9999px`, 음수 margin, `transform`, `text-indent`) |

- 같은 요소에 두 기법이 겹치면 기법별로 한 건씩 보고합니다.
- 위치(`location`)는 `태그.클래스 > 태그.클래스` 꼴의 CSS 선택자이며, 그 페이지에서 정확히 한 요소만 가리키는 것만 보고합니다.
  iframe 안은 `iframe[src="절대주소"] >>> 선택자`, 여러 겹이면 `>>>`를 반복합니다.

### 추가 탐지 유형 (`result_extra.json`, `technique: "ETC"`)

| `extra_finding` | 탐지하는 것 |
|---|---|
| `ZERO_WIDTH(제로폭 문자 삽입)` | 키워드 글자 사이에 보이지 않는 문자(U+200B 등)를 끼운 문구 |
| `VISIBILITY_HIDDEN(visibility:hidden 은닉)` | `visibility:hidden`으로 그리지 않는 문구 |
| `CLIPPED(clip·overflow로 잘라낸 은닉)` | `clip`, `clip-path`, 크기 0~1px + `overflow:hidden`으로 잘라 낸 문구 |
| `KEYBOARD_LAYOUT(한/영 자판 바꿔치기)` | 한글 자판으로 칠 낱말을 영문 상태로 친 것(`zkwlsh` = 카지노) |

### 탐지하지 않는 것

- 눈에 보이는 일반 광고 글(은닉·위장이 없는 것), 이미지 속 글자
- 숨겨져 있지만 광고가 아닌 글: 펼침 메뉴, 탭, 접근성용 숨김 글, 로고 대체 텍스트 등
- 불법 도박 단속·예방을 다루는 보도·안내문(단속·검거·신고·예방 같은 문맥어가 함께 있는 글)
- 로그인이 필요한 페이지, 다른 호스트의 페이지

## 5. 점검 대상 사이트에 주는 부담

- 읽기만 합니다. 폼 제출·로그인·POST를 하지 않고, 로그아웃·삭제 링크는 누르지 않습니다.
- 첨부파일과 이미지·동영상·글꼴은 요청하지 않습니다.
- 페이지가 연달아 열리지 않으면 요청 간격을 벌리고, 계속되면 점검을 멈춥니다("접속 차단 의심으로 중단").
- 운영 중인 사이트는 **동시 브라우저 1~2**를 권장합니다. 한 번에 한 사이트만 점검하세요.

## 6. 키워드 사전 고치기

`conf\keywords_ko.txt`, `conf\keywords_en.txt`를 메모장으로 고치면 다음 실행부터 반영됩니다(UTF-8로 저장).

```
키워드 <탭> 가중치 <탭> 분류 [<탭> 제외 문맥(쉼표로 구분)]
먹튀	3	도박
포커	2	도박	포커스
```

가중치 3은 광고에서만 쓰는 말(하나만 있어도 광고로 봄), 2는 주제어(다른 신호와 함께 봄), 1은 약한 주제어입니다.
제외 문맥은 그 말의 일부로 나온 경우를 세지 않게 합니다(`포커` ⊂ `포커스`).

## 7. 문제 해결

| 증상 | 확인할 것 |
|---|---|
| "브라우저를 실행할 수 없습니다" | 배포 폴더의 `browsers\`가 지워지지 않았는지 확인합니다. 없으면 설치된 Edge → Chrome을 씁니다. |
| "진입 주소에 접속하지 못했습니다" | 주소가 맞는지, 이 PC에서 그 사이트가 열리는지 확인합니다. |
| "접속 차단 의심으로 중단" | 사이트가 요청을 막고 있습니다. 시간을 두고 `--workers 1`로 다시 시도합니다. |
| "시간 예산 도달" | 사이트가 커서 다 돌지 못했습니다. 게시판을 먼저 보므로 광고가 있을 법한 곳은 앞쪽에서 점검됩니다. 예산을 늘리거나 하위 게시판 주소로 따로 점검합니다. |
| 결과 화면이 열리지 않음 | 검은 창에 표시된 주소(`http://127.0.0.1:포트/`)를 브라우저 주소창에 직접 넣습니다. |
| 한글이 깨져 보임(명령줄) | Windows 터미널 또는 기본 명령 프롬프트(한국어)에서 실행합니다. 결과 파일은 항상 UTF-8입니다. |
| 메모리 부족 | 브라우저 하나가 약 650MB를 씁니다. `--workers 1`로 줄입니다. |
